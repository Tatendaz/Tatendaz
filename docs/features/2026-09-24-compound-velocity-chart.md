# Compound velocity chart

`assets/compound-velocity.png` (and `.svg`) is the "Teach it once. Watch it
compound." chart for the agent-teaching tweet. It is generated by
`scripts/render_compound_chart.py`, so the curves and labels are computed
rather than placed by hand.

Compared with the original image:
- Each series is labelled at its endpoint, to the right of the plot. The old
  "Agent you keep teaching" label sat on top of the curve.
- "compounding gains" sits inside the shaded gap between the two lines. This
  replaces the long, floating arrow.
- Faint gridlines, a bolder title, and footer text that no longer crowds the
  axis title.

Regenerate:
```
python3 scripts/render_compound_chart.py <dir with inter-{400,500,600}.woff2>
```
Then screenshot the SVG at 2000×1200 with a headless browser to get the PNG.
